The Hashnode GQL Agent Skill is an official agent skill that teaches AI coding agents how to use the Hashnode GraphQL API . Install it once and Claude Code, Cursor, GitHub Copilot, or any skills-compatible agent can publish posts, update old ones, manage drafts, and upload cover images on your blog. npx skills add Hashnode/gql-skill That's the whole setup, apart from your API token.
